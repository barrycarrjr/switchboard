# Switchboard Documentation

Welcome to the Switchboard documentation. This directory contains architectural records, user guides, and technical references for the Switchboard application.

## Directory Structure

*   **[`design/`](./design/)**: Architectural decisions, RFCs (Request for Comments), and feature planning documents. This is where we record *why* the system works the way it does.
    *   *Example: Provider Failover Handoff Design*
*   **[`guides/`](./guides/)**: Task-oriented guides and tutorials. This is where users can learn *how* to accomplish specific goals.
    *   *Example: Configuring multi-provider fallback lanes*
*   **[`references/`](./references/)**: Exhaustive technical documentation. This is where you look up exact schemas, CLI flags, and API details.
    *   *Example: CLI Command Reference, Configuration File Schemas*
